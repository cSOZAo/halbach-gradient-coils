# Obsolete code archive

These scripts are superseded and kept only to preserve project history. They are
not installed, tested, or supported, and their paths and defaults may be unsafe
for a current design. Do not use them for the active mould workflow.

- `generate_coil_shell.py` — pre-Fusion single-shell boolean
- `gradiente_belen_santi_main_con_leads.py`, `lead_wires.py` — early lead integration
- `barrido_tikhonov_v2.py`, `gradiente_belen_santi_func.py` — parameter sweeps
- `CodigosGitLabOSI/` — golden-angle gradient ports
- `_backup*` — local snapshots

Use the supported [`coilgen/`](../coilgen/) package through
[`run_pipeline.py`](../run_pipeline.py) or [`run_gui.py`](../run_gui.py). Current
installation and usage instructions are in the [project README](../../README.md).

The READMEs below `_pre_consolidation/` describe the archived code as it existed
at that time; they are historical records, not alternative setup instructions.
